# Access Audit v1.0.0

Access Audit is a deterministic local-first preflight tool for saved HTML. This
candidate combines bounded static checks, privacy-minimized replayable reports,
separate Chromium evidence, immutable baseline comparison, expiring report-bound
suppressions and a responsive semantic finding explorer.

## Verification evidence

- Python 3.11, 3.12 and 3.13 quality matrix.
- Seventy-plus risk-based tests and independent artifact replay.
- Locked Chromium and axe-core checks on an original synthetic fixture.
- Byte-identical offline release demo, wheel and canonical source archive.
- Offline wheel installation with no dependency resolution.
- Archive policy, checksum, dependency, vulnerability and secret checks.

## Claim boundary

The software does not determine WCAG conformance. Automated output is preflight
evidence, not certification or proof of usability. NVDA/Firefox and
VoiceOver/Safari sessions must be completed and recorded before publication.

## Upgrade

The public Python API and artifact schemas from v0.3 remain compatible. Package
metadata advances to `1.0.0`; no live website scanning or network behavior is
introduced.
