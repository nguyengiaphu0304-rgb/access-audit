# Synthetic fixture license and purpose

The HTML files in this directory were created specifically for Access Audit and
are dedicated to the public domain under CC0 1.0.

- `passing.html` exercises explicit static signals accepted by v0.1. A
  zero-finding result is not a WCAG or usability claim.
- `failing.html` deterministically exercises every v0.1 rule. Its counts are
  correctness evidence, not measurements from a real website.

The fixtures contain no user, customer, production, scraped, or proprietary
data.
