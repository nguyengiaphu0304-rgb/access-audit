# v1.0.0 publication checklist

## Automated gates

- [ ] Static audit, report replay and tamper rejection.
- [ ] Review, comparison and explorer evidence replay.
- [ ] Chromium, axe-core, keyboard, focus, reflow and reduced-motion fixture checks.
- [ ] Reproducible demo, wheel, canonical sdist and SHA-256 checksums.
- [ ] Offline wheel install and CLI/replay smoke.
- [ ] Python 3.11-3.13 CI, lint, format, typing, tests and dependency audits.

These boxes remain unchecked until the release-candidate commit passes CI. Local
results are recorded in its pull request but do not substitute for required
checks on the exact remote commit.

## Manual accessibility gates

- [ ] NVDA with Firefox session performed and observations recorded.
- [ ] VoiceOver with Safari session performed and observations recorded.
- [ ] Findings reviewed; release notes and residual risks updated if needed.

These boxes are intentionally unchecked. No screen-reader session was available
in the automated Linux environment, and automated browser checks cannot replace
them.

## Publication gates

- [ ] Create annotated tag `v1.0.0` at the verified merge commit.
- [ ] Publish a non-prerelease GitHub Release using `docs/releases/v1.0.0.md`.
- [ ] Attach the verified wheel, canonical sdist and `SHA256SUMS`.
- [ ] Download attachments and verify checksums independently.

Do not publish while any manual or publication gate remains unchecked.
